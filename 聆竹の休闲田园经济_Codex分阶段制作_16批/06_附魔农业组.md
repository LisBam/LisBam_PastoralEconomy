# 9. 新增附魔

本模组新增八种原生体验型附魔：**丰收、耕地行者、田园眷顾、精耕、伐木、屠宰、捷足与夜视**。

它们都可以通过：

1. 附魔台随机获得；
2. 原版图书管理员的附魔书交易随机获得；
3. 商人的珍宝附魔书购买；商人抽到多等级附魔时，再按第 8.5 节的等级概率随机出售其合法等级；
4. 铁砧把附魔书应用到合法装备，或合并同级附魔。

在图书管理员交易中，每种新增附魔作为一个独立稀有候选，不保底；出现权重按“单个稀有附魔书候选”对待。沿用 Java 1.12.2 的旧村民交易体系，不引入 1.14 的工作站、职业方块、村民等级条或补货工作日程。

## 9.1 丰收（Harvest）

| 项目 | 规则 |
|---|---|
| 适用装备 | 木锄、石锄、铁锄、金锄、钻石锄 |
| 最大等级 | III |
| 稀有度 | 稀有，非宝藏限定 |
| 核心效果 | 使用带有丰收的锄头收获成熟作物时，额外增加主要农产品 |
| 互斥 | 与时运（Fortune）互斥 |
| 明确排除 | 南瓜方块、南瓜茎以及连接南瓜的茎全部不受丰收影响 |

丰收只在作物成熟并能正常收获时触发。种子、稀有副产物和经验默认仍按原版规则结算，不跟着丰收复制。

### 9.1.1 精确增产数值

| 作物 | 丰收 I | 丰收 II | 丰收 III | 说明 |
|---|---:|---:|---:|---|
| 胡萝卜 | `Binomial(2, 4/7)` | `Binomial(4, 4/7)` | `Binomial(6, 4/7)` | 平均额外约 +1.14 / +2.29 / +3.43 |
| 马铃薯 | `Binomial(2, 4/7)` | `Binomial(4, 4/7)` | `Binomial(6, 4/7)` | 只额外给普通马铃薯，不复制毒马铃薯判定 |
| 小麦 | `Binomial(2, 1/2)` | `Binomial(4, 1/2)` | `Binomial(6, 1/2)` | 平均额外 +1 / +2 / +3 小麦；不额外复制种子 |
| 甜菜根 | `Binomial(2, 1/2)` | `Binomial(4, 1/2)` | `Binomial(6, 1/2)` | 平均额外 +1 / +2 / +3 甜菜根；不额外复制种子 |
| 下界疣 | `UniformInt(0,2)` | `UniformInt(0,4)` | `UniformInt(0,6)` | 平均额外 +1 / +2 / +3 |
| 西瓜 | `UniformInt(1,2)` | `UniformInt(2,4)` | `UniformInt(3,6)` | 额外西瓜片不沿用原版时运的总量 9 片上限 |
| 可可果 | 固定 +1 可可豆 | 固定 +2 | 固定 +3 | 只对成熟可可触发 |

`Binomial(n,p)` 表示独立进行 n 次、每次成功概率为 p 的 +1 判定；`UniformInt(a,b)` 表示在闭区间 a～b 内等概率取整数。

甘蔗、仙人掌、树木等没有明确“成熟收获阶段”的整块生长资源不受丰收影响。

### 9.1.2 与时运共存异常

正常玩法不会得到“丰收 + 时运”同一把锄头。若因命令、旧存档或其他模组产生异常共存，则农作物只按丰收的模组增产规则结算，不再额外叠加另一套模组补发，避免爆炸式增产。

## 9.2 耕地行者（Farmland Walker）

| 等级 | 效果 |
|---:|---|
| I | 穿戴者不会因跳跃、落地或正常移动把耕地踩回泥土。 |
| II | 完整继承 I；站在耕地上时水平移动速度为正常有效速度的 **1.20×**。 |
| III | 完整继承 I；站在耕地上时水平移动速度为正常有效速度的 **1.35×**。 |

其他规则：

- 适用于皮革靴、锁链靴、铁靴、金靴、钻石靴。
- II/III 的加速只在玩家实际站在耕地上时生效；离开立刻消失。
- 不增加跳跃高度。
- 骑乘、飞行等状态不获得耕地加速。
- 可以与保护、火焰保护、爆炸保护、弹射物保护、摔落保护、深海探索者、冰霜行者、耐久、经验修补、绑定诅咒、消失诅咒等合法靴子附魔共存。

## 9.3 田园眷顾（Pastoral Favor）

| 项目 | 规则 |
|---|---|
| 适用装备 | 皮革帽子、锁链头盔、铁头盔、金头盔、钻石头盔 |
| 最大等级 | IV |
| 稀有度 | 稀有，非宝藏限定 |
| 核心效果 | 玩家亲自收获成熟作物或完成一次合法种植时，有概率获得经验值 |
| 每次成功奖励 | **1 点经验值**；直接计入玩家经验，不额外生成可被他人抢走的经验球 |

等级概率：

| 等级 | 每次合法收获/种植获得 1 点经验的概率 |
|---:|---:|
| I | 10% |
| II | 20% |
| III | 30% |
| IV | 40% |

触发范围与规则：

- “成熟作物收获”包括成熟小麦、胡萝卜、马铃薯、甜菜根、下界疣和成熟可可果；西瓜方块和南瓜方块本身也视为可收获农作物。
- “种植”包括成功放置小麦种子、胡萝卜、马铃薯、甜菜种子、南瓜种子、西瓜种子、下界疣或可可豆，并且对应方块确实成功进入世界。
- 只对玩家本人主动完成的种植/收获判定；活塞、漏斗、其他自动化、方块自然更新以及其他实体造成的变化不触发。
- 一次种植或一次成熟收获最多进行 1 次田园眷顾判定，不按掉落物数量重复计算。
- 经验奖励不受丰收、时运、精耕或其他掉落增益重复放大。

## 9.4 精耕（Fine Cultivation）

| 项目 | 规则 |
|---|---|
| 适用装备 | 木锄、石锄、铁锄、金锄、钻石锄 |
| 最大等级 | IV |
| 稀有度 | 稀有，非宝藏限定 |
| 核心效果 | 使用带有精耕的锄头收获成熟耕地作物时，有概率立即在原位置重新种植同种作物 |
| 与丰收 | 可以共存；先完成本次掉落结算，再执行补种 |

| 等级 | 自动重新种植概率 |
|---:|---:|
| I | 25% |
| II | 50% |
| III | 75% |
| IV | 100% |

补种规则：

- 只作用于种在**耕地**上的小麦、胡萝卜、马铃薯和甜菜根；下界疣、可可、甘蔗、仙人掌、南瓜/西瓜果实与茎不属于精耕目标。
- 只有作物达到成熟阶段并由玩家使用带精耕的锄头正常收获时才判定。
- 触发成功后需要消耗 **1 个对应的种植物**：小麦消耗小麦种子，胡萝卜消耗胡萝卜，马铃薯消耗马铃薯，甜菜根消耗甜菜种子。
- 优先从本次收获产生的对应物品中扣除 1 个；若本次掉落不足，则从玩家主物品栏/快捷栏中寻找并消耗 1 个。
- 若没有可用种植物，则本次不补种，也不会凭空生成种子或作物。
- 补种后的作物从最初生长阶段开始，不保留原成熟度。
- 精耕不会额外改变耕地湿润度，也不会把已变成泥土的方块强制恢复成耕地。

## 验收标准

- 四种附魔均能通过附魔书+铁砧应用到合法装备，非法装备被拒绝。
- 丰收统计抽样符合冻结概率，且种子/毒马铃薯等不被错误复制。
- 耕地行者 I 能阻止玩家踩坏田；II/III 移速倍率正确，离田恢复。
- 田园眷顾每次合法动作最多 +1 XP，概率按等级，自动化不触发。
- 精耕 IV 在有种植物时 100% 补种；没种植物不凭空补种；其余等级概率正确。
- 丰收+精耕同锄头能按“先掉落、再扣种植物补种”稳定工作。
