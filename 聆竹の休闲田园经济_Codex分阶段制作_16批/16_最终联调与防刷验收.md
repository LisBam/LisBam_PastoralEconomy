# Codex 第 16 批：多人持久化、防刷钱、平衡与全模组最终验收

这是收尾批次。不要再新增玩法；目标是把此前系统作为一个完整模组做多人、存档、重启、并发、防复制与冻结数值对照测试，修复发现的问题。

## 固定项目约束（本批次必须遵守）

- 游戏：Minecraft Java Edition 1.12.2。
- 模组名称：`聆竹の休闲田园经济`。
- 开发基线：Java 8；Minecraft Forge 1.12.2 Recommended `14.23.5.2859` MDK。
- 建议固定 `modid = lingzhu_farm_economy`，Java 根包名使用不冒充他人域名的自有命名；如果仓库已经有稳定 modid/package，则保持现有值，不要为了本任务重命名整个项目。
- 只能使用 1.12.2 存在的原版内容与 1.12.2 Forge API；禁止引入 1.13+ 的扁平化 ID、数据包、工作站/钟/袭击等后续机制。
- 所有金币、市场、库存、线路等关键资产必须由服务端权威处理；客户端只负责显示与发送请求，不能直接决定资产结果。
- 冻结数值不可擅自“平衡调整”、取整替换或简化。如果实现上遇到冲突，优先保持内容规则，并在最终汇报中说明实现取舍。
- 不要提前实现后续批次的完整功能；允许为了接口依赖创建最小占位类/接口，但不得把未要求系统一次性写完。
- 修改前先检查当前工程已有实现，复用已经完成的基础设施，禁止重复造第二套存档、网络、GUI 或注册系统。
- 完成后必须至少执行 `gradlew build`（Windows 可用 `gradlew.bat build`）并修复本批次引入的编译错误。

# 15. 多人、存档与防刷钱规则

## 15.1 多人数据归属

| 数据 | 归属 |
|---|---|
| 玩家金币 | 每名玩家独立 |
| 已解锁线路 | 每名玩家独立 |
| 目的地别名 | 每名玩家独立 |
| 村庄交通节点的世界状态 | 全世界共享 |
| 当日商品行情 | 全世界共享 |
| 作物历史行情曲线 | 全世界共享并随世界存档持久保存 |
| 每名商人的当日商品列表 | 全世界共享 |
| 稀有/珍宝库存消耗 | 该商人当日全体玩家共享 |

## 15.2 交易安全

- 最终确认交易时必须重新检查当天价格、余额、库存和背包状态。
- 购买前必须确认背包能完整放下商品；放不下就拒绝购买且不扣钱。
- 出售时必须先真正移除商品，再增加金币。
- 任何异常都不得导致重复发货、重复加钱、负余额或吞物品。
- 同一名玩家同一时刻只能完成一笔最终资产操作，避免快速双击造成复制或重复扣款。

## 15.3 防刷规则

| 风险 | 规则 |
|---|---|
| 退出重进刷商品 | 同一天同一商人的列表固定 |
| 重启刷库存 | 当天已消耗库存不会恢复 |
| 跨商人倒卖 | 常规收购池只收农业/畜牧可再生产物，不回购矿物与珍宝 |
| 同日买卖套利 | 同一商品若同时存在买卖入口，使用同一日行情倍率，且基础买价必须明显高于基础卖价 |
| 背包满吞钱 | 购买失败且不扣钱 |
| 传送失败吞钱 | 不扣钱或全额退款 |
| 搬站逃接入费 | 除首个免费自建站外，一律按到最近已接入节点距离收费 |
| 拆村庄站复制 | 村庄站不作为普通可掉落方块 |
| 金币异常 | 不设置人为余额上限；余额不得出现负数，也不得因数值溢出出现清零、变负或异常回绕 |

# 16. 平衡验算

以下均按基础价计算，不考虑当天行情波动。

| 目标 | 基础计算 | 经营意义 |
|---|---|---|
| 铁资源起步 | 铁锭 4 个 = 360；72 小麦 ×5 = 360 | 一小块早期麦田即可开始获得桶、剪刀等铁工具资源。 |
| 钻石镐 | 3 钻石 ×1,600 = 4,800 | 约 960 小麦，或约 283 南瓜。 |
| 下界之星 | 12,000 | 约 2,400 小麦，或约 706 南瓜；允许不打凋灵但仍需明显经营积累。 |
| 附魔金苹果 | 25,000 | 约 5,000 小麦；属于高价收藏/应急物品。 |
| 鞘翅 | 120,000 | 约 24,000 小麦，或约 7,059 南瓜；长期经营目标。 |
| 500 格新村庄 | 接入 1,000；单次旅行 100 | 早期能负担，但不能无成本频繁跨村。 |
| 2,000 格新村庄 | 接入 2,800；单次旅行 280 | 中期通过扩大农场换取跨村经营效率。 |

价格约束：

- 即使农产品处于最高价、钻石处于最低价，也不能让几十个基础作物轻易换到一颗钻石。
- 普通资源的作用是减少重复采集；稀有/珍宝价格必须保留长期经营目标。
- 作为“种苗”出售的农作物不能形成“买回来立刻卖掉就赚钱”的套利。
