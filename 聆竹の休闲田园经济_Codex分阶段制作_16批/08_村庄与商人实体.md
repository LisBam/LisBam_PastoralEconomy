# 6. 商人

商人是独立 NPC，不属于原版村民职业。

| 项目 | 规则 |
|---|---|
| 名称 | 商人 |
| 外观 | 默认使用 Steve 风格人物外观作为当前占位形象 |
| 营业时间 | 全天 24 小时 |
| 战斗能力 | 无主动攻击能力 |
| 受伤/死亡 | 可以被正常伤害和杀死 |
| 自然消失 | 不会自然消失 |
| 活动范围 | 以所属交通站为中心约 12 格活动 |
| 过远归位 | 距所属交通站超过 32 格时回到站点附近 |

## 6.1 村庄商人数

每个有效村庄维持 **3～8 名商人**。目标数量根据村民数计算：

`目标商人数 = clamp(ceil(村民数 ÷ 5), 3, 8)`

| 村民数 | 目标商人数 |
|---:|---:|
| 2～15 | 3 |
| 16～20 | 4 |
| 21～25 | 5 |
| 26～30 | 6 |
| 31～35 | 7 |
| 36+ | 8 |

商人可以被玩家、怪物或其他伤害来源杀死。只要该村庄仍然有效，存活商人数量低于当前目标值时就会**自动补充至目标数量**，因此杀死商人不会永久减少村庄的商人规模。目标值始终限制在 3～8 名。


# 13. 村庄与交通站

Java 1.12.2 使用旧村庄体系。本模组以 **1.12.2 原版有效村庄/村民聚落**为基础识别和维护村庄内容，不使用后来版本的钟、工作站和床职业系统。

## 13.1 村庄识别与维护规则

| 项目 | 数值/规则 |
|---|---|
| 维度 | 仅主世界 |
| 最低村民数 | 2 名 |
| 村民聚落参考范围 | 128 格 |
| 同一聚落连接参考距离 | 64 格 |
| 同一村庄去重参考距离 | 160 格 |
| 交通站放置范围 | 村庄中心附近约 12 格内寻找安全位置 |
| 商人数 | `clamp(ceil(村民数/5),3,8)` |

村庄交通站和已经产生的玩家线路状态会持久保存。村民数量变化时按第 6.1 节维护商人数量；商人死亡后会自动补足到当前目标。

## 13.2 村庄交通站

- 每个有效村庄在需要激活交通功能时恰好拥有 1 个村庄交通站。
- 站点应位于村庄中心附近的安全位置，不覆盖箱子、门、农田等重要设施。
- 村庄站不能被正常拆掉并掉落成可复制物品。
- 如果村庄站因异常方式消失，在该村庄再次活跃时会恢复。

## 13.3 “最近未解锁村庄”

## 验收标准

- 2～15 村民=3 商人；16～20=4；21～25=5；26～30=6；31～35=7；36+=8。
- 村民数量增减后商人数最终收敛到正确目标。
- 杀死商人后能补足但不会瞬间刷出无限实体。
- 商人不会自然 despawn，离站 >32 格会回到附近。
- 同一有效村庄不会正常生成多个村庄交通站；异常破坏后能恢复。
- 重启服务器后村庄/站点/商人归属保持。
