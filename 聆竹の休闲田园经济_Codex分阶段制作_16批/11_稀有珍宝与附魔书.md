## 固定项目约束（本批次必须遵守）

- 游戏：Minecraft Java Edition 1.12.2。
- 模组名称：`聆竹の休闲田园经济`。
- 开发基线：Java 8；Minecraft Forge 1.12.2 Recommended `14.23.5.2859` MDK。
- 建议固定 `modid = lingzhu_farm_economy`，Java 根包名使用不冒充他人域名的自有命名；如果仓库已经有稳定 modid/package，则保持现有值，不要为了本任务重命名整个项目。
- 只能使用 1.12.2 存在的原版内容与 1.12.2 Forge API；禁止引入 1.13+ 的扁平化 ID、数据包、工作站/钟/袭击等后续机制。
- 所有金币、市场、库存、线路等关键资产必须由服务端权威处理；客户端只负责显示与发送请求，不能直接决定资产结果。

- 不要提前实现后续批次的完整功能；允许为了接口依赖创建最小占位类/接口，但不得把未要求系统一次性写完。
- 修改前先检查当前工程已有实现，复用已经完成的基础设施，禁止重复造第二套存档、网络、GUI 或注册系统。

# 11. 资源可达性原则

本模组的经济目标不是把几百个衍生方块全部直接塞进商人列表，而是让玩家通过：

**出售可再生产物 → 金币 → 购买基础/稀有资源 → 使用 Java 1.12.2 原版合成、熔炼、酿造、附魔与种植**

最终获得完整生存资源链中的关键物品和主要收藏目标。

## 11.1 直接覆盖的关键门槛

- 下界/末地与战斗资源：烈焰棒、末影珍珠、恶魂之泪、凋灵骷髅头颅、潜影壳、龙息、下界之星等。
- 结构/终局收藏：鞘翅、附魔金苹果、龙首、龙蛋、不死图腾、海绵等。
- 非普通配方装备：锁链甲、铁/金/钻石马铠、鞍、命名牌。
- 稀有矿石形态：煤矿石、铁矿石、金矿石、红石矿石、青金石矿石、下界石英矿石、钻石矿石、绿宝石矿石。
- 收藏：1.12.2 的 12 张音乐唱片、原版可生存获得的怪物头颅。
- 宝藏附魔：经验修补、冰霜行者、绑定诅咒、消失诅咒，以及本模组新增附魔。
- 环境入口：六种树苗、下界疣、紫颂花、菌丝、灰化土、睡莲、藤蔓、各类 1.12.2 花卉等。

## 11.2 不直接出售但可以由原料得到的内容

例如木板、楼梯、栅栏、石砖、彩色玻璃、混凝土、陶瓦、红石元件、药水、信标、末地水晶、潜影盒等，只要所需原料已经可由市场或原版可再生产物取得，就不需要再占商人的每日商品栏位。

## 11.3 明确排除

不要求经济系统提供以下物品：

- 创造/命令专用：命令方块、屏障、结构方块等。
- 生成蛋。
- 无法作为正常物品持有的世界状态方块。
- Java 1.12.2 正常 Survival 无法获得为物品的内容，例如基岩、末地传送门框架、刷怪笼等。

## 验收标准

- 稀有/珍宝所有表项准确无遗漏，库存准确。
- 每名商人同日最终正好 10 个出售栏：4/3/2/1。
- 多等级特殊附魔书概率表与价格表完全一致；单日抽到的等级固定。
- 珍宝买走后当天不会因重登/重启恢复。
- 12 张唱片仅为 Java 1.12.2 的 12 张，不出现后续版本唱片。
- 资源目录不出现 1.12.2 后才存在的内容。
