## 3.2 怪物主动攻击规则

本模组现在只修改以下指定怪物对**玩家**的主动仇恨逻辑；除本节明确列出的怪物外，其他所有敌对、中立或 Boss 生物的攻击目标与主动攻击行为均完全保留 Java 1.12.2 原版规则。

### 3.2.1 不会主动攻击玩家的怪物

| 类别 | 受修改的 Java 1.12.2 生物 |
|---|---|
| 僵尸系 | 僵尸、僵尸村民、尸壳 |
| 骷髅系 | 骷髅、流浪者 |
| 苦力怕 | 苦力怕；充能苦力怕属于同一规则 |
| 末影人 | 末影人 |
| 蜘蛛系 | 蜘蛛 |

对上述生物统一应用以下规则：

- 不会仅因为看见、靠近、注视、巡逻、目标搜索或玩家进入其通常警戒范围而主动把玩家设为攻击目标。
- 玩家先对其造成直接伤害后，允许按该生物原版攻击方式把该玩家作为反击目标；反击结束与仇恨解除继续采用原版逻辑。
- 该修改**只针对“主动攻击玩家”这一关系**。这些生物原本会攻击村民、铁傀儡、雪傀儡或其他实体的行为继续按原版执行，不因本模组统一取消。
- 铁傀儡、雪傀儡以及其他生物对这些怪物的目标选择同样保持原版，不再进行全局和平化修改。
- 自然生成、移动、寻路、掉落、燃烧、环境互动及其他未特别说明的 AI 行为保持原版。

**僵尸猪人不属于本次主动攻击修改对象。**它本来就是中立生物，继续完整采用 Java 1.12.2 原版的群体仇恨与反击逻辑。

### 3.2.2 其他怪物

除上表外的怪物全部不修改。包括但不限于烈焰人、恶魂、守卫者、远古守卫者、末影螨、唤魔者、卫道士、恼鬼、女巫、史莱姆、岩浆怪、蠹虫、潜影贝、凋灵和末影龙等，均可以继续按照 Java 1.12.2 原版规则主动攻击玩家。

### 3.2.3 特殊规则

- **末影人**：玩家直视末影人不会使其因注视而主动进入对玩家的敌对状态；玩家直接攻击末影人后，末影人可以正常反击。
- **苦力怕主动攻击**：苦力怕不会仅因发现或靠近玩家而主动追踪、接近和点燃。玩家直接攻击苦力怕后，苦力怕允许进入反击状态，并可按原版方式接近、点燃和爆炸。玩家使用原版允许的方式主动点燃苦力怕时，同样可以正常爆炸。
- **苦力怕爆炸**：普通苦力怕与充能苦力怕的爆炸均**不会破坏任何方块**，不改变地形，也不会炸毁耕地、作物、箱子、建筑或掉落方块物品；但爆炸对玩家、生物及其他实体造成的伤害、击退、声音、粒子和其他实体层面的爆炸效果继续保留。充能苦力怕仍使用其原版更强的实体爆炸伤害。
- 苦力怕的“不破坏方块”规则只作用于苦力怕自身爆炸，不修改 TNT、床爆炸、末地水晶、凋灵或其他爆炸来源。

## 3.3 农田骚扰

为了让这些不会主动攻击玩家的怪物仍然对农场防护有一点意义，以下怪物在没有战斗目标时会低频骚扰农田：

- 僵尸系：僵尸、僵尸村民、尸壳
- 蜘蛛系：蜘蛛
- 骷髅系：骷髅、流浪者
- 末影人：末影人

### 可破坏目标

- 只作用于耕地及其直接承载的 1.12.2 作物：小麦、胡萝卜、马铃薯、甜菜、南瓜茎、西瓜茎。
- 有作物时优先破坏作物；不会一次同时把下方耕地也踩回泥土。
- 空耕地可以被踩回普通泥土。
- 不破坏普通泥土、草方块、原木、门、围栏、箱子、红石、甘蔗、仙人掌等其他建筑/农场设施。
- 每次成功骚扰最多改变 1 个方块。

### 触发与限速数值

| 参数 | 数值 |
|---|---:|
| 附近必须存在玩家 | 48 格内至少 1 名存活玩家 |
| 单只怪物候选检查间隔 | 200～320 ticks（10～16 秒） |
| 搜索半径 | 水平 8 格，垂直 ±3 格 |
| 真正破坏距离 | ≤1.8 格 |
| 候选倾向 | 75% 作物 / 25% 空耕地 |
| 成功后的单体冷却 | 45～75 秒 |
| 区域限额半径 | 32 格 |
| 区域统计窗口 | 5 分钟 |
| 区域最大破坏量 | 6 次 / 5 分钟 |

因此怪物只能形成小规模、可修复的农田损失，不会在玩家短暂离开时快速拆毁整片农场。

## 验收标准

- 指定怪物看到/靠近玩家时不会主动攻击；玩家先攻击后可以反击。
- 僵尸猪人、女巫、烈焰人等未列出生物行为与原版一致。
- 直视末影人不会触发主动仇恨；攻击它仍会反击。
- 苦力怕自然发现玩家不追踪点燃；被玩家直接攻击后可反击并爆炸。
- 苦力怕爆炸不破坏任何方块，但实体仍受伤；TNT 仍能正常炸方块。
- 农田骚扰一次最多改 1 方块；32 格区域 5 分钟最多 6 次；单体成功后 45～75 秒冷却。
- 只破坏指定耕地作物或空耕地，不破坏箱子、红石、围栏、甘蔗等。
