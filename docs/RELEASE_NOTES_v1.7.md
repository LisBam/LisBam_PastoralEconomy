# 聆竹の休闲田园经济 v1.7

面向 **Minecraft Java Edition 1.12.2 / Forge 14.23.5.2859** 的休闲田园经济模组。

把 1.12.2 的生存主循环调整为 **休闲种田 + 蟹笼捕捞 + 每日行情 + 商人交易 + 绿宝石现货 + 村庄交通 + 长期经营**。原版的挖矿、探索、下界与末地、Boss 战和传统战斗全部保留，本模组只是额外提供了一条不依赖挖矿和刷怪的资源获取路径。

## 安装

1. 安装 **Minecraft 1.12.2** 并装好 **Forge 14.23.5.2859**（或同系列 14.23.5.x）。
2. 下载下方 Assets 中的 `LisBam_PastoralEconomy-1.7.jar`。
3. 把 JAR 放进 `.minecraft/mods/`，用 **Java 8** 启动游戏。

客户端与服务器必须使用同一份完整 JAR。本模组同时是 Coremod，请勿与其他改写同一原版类的模组混用。

## 本版主要内容

- **金币与经济**：屏幕右上角余额 HUD，1 小麦基础卖价 50 金币，死亡扣除随机 10%～30% 余额。
- **每日市场行情**：按 Minecraft 世界日刷新，同日重登/重启/切维度不重抽；波动率按商品类别分档。
- **市场行情书**（书 ×1 + 小麦 ×1）：随时查看 29 种收购商品与购买目录，含最近 30 个世界日价格曲线与中文/拼音搜索，库存 Tooltip 直接显示今日价。
- **绿宝石现货「炒币」**：用金币买卖真实原版绿宝石，独立日价 300～3,000 金币/个，买卖手续费各 4%。
- **商人 NPC**：随机中文姓名与四种农作服装，全天营业；每村至少 3 名并自动补足，每人每日收购 6 项、出售 8 项。
- **交易凭证与出货箱**：授权原版箱子参与交易；出货箱每天清晨按当天收益 70% 自动结算给凭证所属玩家。
- **蟹笼**：靠水自动捕捞，20 格容器支持钓竿附魔继承与生肉饵料，可用漏斗全自动收集。
- **十三种新增附魔**：丰收、耕地行者、田园眷顾、精耕、伐木、屠宰、捷足、夜视、攻速、范围、掉落吸附、百炼如新、束锋诅咒。
- **交通网络与肩部装备**：付费接入村庄交通站；原版背包新增肩部槽，可装备鞘翅、翅膀与 27/54/108 格三种背包。
- **区块加载器**：红石充能时仅保持自身 1 个区块加载。
- **休闲化规则**：首次启用默认开启死亡保留物品；主世界不再自然生成敌对生物（刷怪笼不受影响）；敌对生物行为完全保留 1.12.2 原版；成年牛每个世界日只能挤奶 1 次。

完整玩法、配方与冻结数值见仓库中的 [`聆竹の休闲田园经济_模组内容书.md`](https://github.com/LisBam/LisBam_PastoralEconomy/blob/master/%E8%81%86%E7%AB%B9%E3%81%AE%E4%BC%91%E9%97%B2%E7%94%B0%E5%9B%AD%E7%BB%8F%E6%B5%8E_%E6%A8%A1%E7%BB%84%E5%86%85%E5%AE%B9%E4%B9%A6.md)。
