## 本批次必须实现

- 正式注册交通方块及无序配方：指南针×1 + 铁块×1 + 红石粉×1 -> 交通方块×1。
- 只支持主世界交通；下界/末地不允许作为交通站接入。
- 每名玩家首次进入世界获得 1 个交通方块；仅一次，丢失不补发。
- 玩家第一次把“开局赠送的交通方块”作为自己的第一个自建网络节点时免费接入；此免费资格每人只用一次。
- 后续任何新自建站按“到自己最近已接入节点的水平距离”收费：`D=floor(sqrt(dx^2+dz^2))`；Y 不参与。
- 接入费：`round10(400 + 1.20×D)`，最低 10。校验点必须为：D=0 -> 400；250 -> 700；500 -> 1,000；1,000 -> 1,600；2,000 -> 2,800；5,000 -> 6,400；10,000 -> 12,400。
- 节点可从个人网络中移出：只移除该玩家接入状态，不拆方块、不影响别人；移出后不参与最近节点计算。
- 重新激活按正常接入费重算；若已没有任何接入节点，则 D=0、收费 400；首个免费资格用过不能恢复。
- 每名玩家独立保存节点接入状态与别名。
- 命名限制：最大 24 Unicode 字符、不可空、不可控制字符/换行/格式码、同一玩家不可重名；默认命名按内容书规则。
- 本批交通 GUI 至少能完成：当前位置、金币、当前自建站是否接入、接入按钮、节点列表、移出、重命名。

# 12. 交通网络

## 12.1 交通方块

| 项目 | 数值/规则 |
|---|---|
| 名称 | 交通方块 |
| 支持维度 | 仅主世界 |
| 首次赠送 | 每名玩家首次进入世界获得 1 个 |
| 丢失后补发 | 不补发，可自行合成 |
| 合成 | 指南针 ×1 + 铁块 ×1 + 红石粉 ×1 → 交通方块 ×1（无序） |
| 村庄站 | 每个有效村庄恰好 1 个，受保护 |
| 玩家自建站 | 可自行放置和拆除 |
| 跨维度旅行 | 不支持；下界/末地继续使用原版传送门 |

## 12.2 线路接入

- 玩家首次把开局赠送的交通方块作为自己的第一个自建网络节点时，**免费接入**。
- 之后任何新自建站都必须按“到自己最近已接入节点的水平距离”支付接入费。
- 玩家不能把一个交通方块搬到远处就绕过线路费用。

## 12.3 旅行距离

只计算两个站点在主世界的水平距离：

`D = floor(sqrt((x1-x2)^2 + (z1-z2)^2))`

Y 高度不参与收费。

## 12.5 村庄线路/自建站接入费

`接入费(D) = round10(400 + 1.20 × D)`

其中 `round10` 表示四舍五入到最接近的 10 金币，最低 10 金币。

## 12.6 节点移出与重新激活

玩家可以在交通网络管理界面中，把任意一个自己已接入的节点**移出交通网络**。

- 移出节点只取消该玩家对该节点的接入状态，不会摧毁交通方块，也不会影响其他玩家的线路。
- 被移出的节点不能作为出发点或目的地使用，也不再计入该玩家“最近已接入节点”的距离计算。
- 被移出的交通方块需要**重新激活**后才能再次使用。
- 重新激活时视为一次新的线路接入，按当前节点到该玩家最近已接入节点的水平距离重新计算并收取正常接入费。
- 如果玩家移除后已经没有任何已接入节点，则重新激活一个节点时按 D=0 计算，基础接入费为 400 金币。
- “首个自建站免费接入”是每名玩家仅有一次的资格；已经使用后，不能通过移出节点再获得一次免费激活。
- 移出村庄节点不会删除村庄本身或村庄交通站；之后仍可重新定位该村庄并重新付费接入。

## 验收标准

- 首次赠送恰好一次；死亡/重登不重复赠送。
- 首个赠送站首次接入免费；第二个自建站开始正常收费。
- D 和接入费在 0/250/500/1000/2000/5000/10000 示例点与内容书一致。
- 移出节点后不能作为网络节点参与收费距离；重激活重新收费。
- 免费资格不能通过拆站/移出/重登刷回。
- 多人对同一个实体交通方块可以有各自独立接入/别名状态。
