## 9.5 伐木（Felling）

| 项目 | 规则 |
|---|---|
| 适用装备 | 木斧、石斧、铁斧、金斧、钻石斧 |
| 最大等级 | I |
| 稀有度 | 稀有，非宝藏限定 |
| 核心效果 | 使用带有伐木的斧头砍伐树木原木时，连锁破坏判定属于同一棵树的树干与树叶 |

具体规则：

- 支持 Java 1.12.2 的橡树、云杉、白桦、丛林树、金合欢和深色橡树。
- 只有直接破坏原木并且周围结构能被判定为一棵正常树木时才启动连锁；单独摆放的原木柱、木屋、围墙等没有正常树冠的建筑木材不会主动触发整片连锁。
- 连锁会处理该树的原木与树冠叶片，但**不会沿相邻树冠继续连锁到另一棵树**。
- 所有被连锁破坏的方块都按正常方块掉落规则结算；叶片仍可正常掉落树苗、苹果等对应物品。
- 每成功连锁破坏 1 个原木或叶片，斧头都按正常破坏行为消耗对应耐久；若斧头在过程中损坏，连锁立即停止。
- 耐久附魔仍按原版规则对每次耐久消耗分别判定。
- 创造模式不消耗工具耐久，但仍可使用伐木效果。

## 9.6 屠宰（Slaughter）

| 项目 | 规则 |
|---|---|
| 适用装备 | 木剑/石剑/铁剑/金剑/钻石剑；木斧/石斧/铁斧/金斧/钻石斧 |
| 最大等级 | III |
| 稀有度 | 稀有，非宝藏限定 |
| 互斥 | 与锋利、亡灵杀手、节肢杀手互斥；与抢夺互斥 |
| 核心效果 | 对动物造成额外伤害，并显著提高动物死亡时的常规掉落数量 |

### 9.6.1 额外伤害

屠宰对合法动物目标的伤害加成采用与 Java 1.12.2 **亡灵杀手对亡灵生物相同的每级数值**：

| 等级 | 对动物额外攻击伤害 |
|---:|---:|
| I | +2.5 |
| II | +5.0 |
| III | +7.5 |

该额外伤害只在本次攻击目标属于动物时生效；攻击怪物、村民、玩家、铁傀儡等其他实体时不获得屠宰伤害加成。

### 9.6.2 动物范围

屠宰作用于 Java 1.12.2 中可按动物处理的生物，包括牛、哞菇、猪、羊、鸡、兔、马、驴、骡、羊驼、狼、豹猫与鹦鹉。驯服状态不会取消屠宰判定，因此玩家仍需自行避免误伤宠物。

### 9.6.3 掉落数量

屠宰不使用原版抢夺算法，而是在动物正常死亡掉落结算完成后，对**本次已经实际生成的常规动物死亡掉落数量**进行强化：

| 等级 | 常规死亡掉落平均倍率 |
|---:|---:|
| I | 1.50× |
| II | 2.00× |
| III | 2.50× |

- 对于倍率产生的小数部分，按对应小数概率再额外增加 1 个。例如 1 个物品在屠宰 I 下得到 1.5×，则最终为 1 个并有 50% 概率再 +1。
- 掉落倍率作用于肉、皮革、羽毛、羊毛、兔子皮等正常死亡掉落；不会凭空把原本未掉落的稀有物品变成必掉。
- 若兔子脚等稀有掉落本次已经成功产生，则其数量也可以被倍率放大；若原判定为 0，则仍为 0。
- 经验值不受屠宰倍率影响。
- 由于屠宰与抢夺互斥，正常玩法不会同时叠加两套掉落增益；屠宰的掉落强化整体定位高于同级抢夺。

## 9.7 捷足（Fleetfoot）

| 项目 | 规则 |
|---|---|
| 适用装备 | 皮革靴、锁链靴、铁靴、金靴、钻石靴 |
| 最大等级 | IV |
| 稀有度 | 稀有，非宝藏限定 |
| 核心效果 | 持续提高穿戴者的地面移动速度，不显示药水状态 |

每一级提供等同于对应等级速度效果的移动速度增幅，即每级 **+20%**：

| 等级 | 移动速度增幅 |
|---:|---:|
| I | +20% |
| II | +40% |
| III | +60% |
| IV | +80% |

其他规则：

- 捷足只提高正常移动速度，不增加跳跃高度。
- 骑乘实体时不把捷足加成转移给坐骑。
- 捷足不是药水 Buff，不显示状态图标、粒子或持续时间。
- 可以与耕地行者共存；站在耕地上时，先计算捷足及其他正常移动速度，再应用耕地行者 II/III 的耕地专属倍率。
- 如果玩家同时拥有原版速度药水效果，两者可以正常叠加；捷足本身不会覆盖或清除药水效果。

## 9.8 夜视（Night Vision）

| 项目 | 规则 |
|---|---|
| 适用装备 | 皮革帽子、锁链头盔、铁头盔、金头盔、钻石头盔 |
| 最大等级 | I |
| 稀有度 | 稀有，非宝藏限定 |
| 核心效果 | 穿戴后直接增强佩戴者在黑暗环境中的视觉，使暗处保持清晰可见 |

具体规则：

- 夜视**不是原版夜视药水效果**，不会给予 `Night Vision` 状态，不显示药水图标、粒子或持续时间。
- 只改变佩戴者自己的视觉表现，不生成真实光源，也不修改任何方块的实际光照等级。
- 不影响怪物生成、作物生长、红石、光照检测或其他依赖世界光照值的机制。
- 多人游戏中只对实际佩戴该头盔的玩家生效，其他玩家看到的世界亮度不受影响。
- 取下头盔后立即恢复正常暗处视觉。

## 9.9 附魔书合并

- 丰收 I + 丰收 I → 丰收 II；丰收 II + 丰收 II → 丰收 III。
- 耕地行者 I + 耕地行者 I → 耕地行者 II；耕地行者 II + 耕地行者 II → 耕地行者 III。
- 田园眷顾 I + I → II；II + II → III；III + III → IV。
- 精耕 I + I → II；II + II → III；III + III → IV。
- 屠宰 I + I → II；II + II → III。
- 捷足 I + I → II；II + II → III；III + III → IV。
- 伐木与夜视最高仅 I 级，不能继续升级。
- 任何附魔达到各自最高等级后都不能继续升级。
- 应用和合并需要正常消耗经验。

本模组新增八种原生体验型附魔：**丰收、耕地行者、田园眷顾、精耕、伐木、屠宰、捷足与夜视**。

它们都可以通过：

1. 附魔台随机获得；
2. 原版图书管理员的附魔书交易随机获得；
3. 商人的珍宝附魔书购买；商人抽到多等级附魔时，再按第 8.5 节的等级概率随机出售其合法等级；
4. 铁砧把附魔书应用到合法装备，或合并同级附魔。

在图书管理员交易中，每种新增附魔作为一个独立稀有候选，不保底；出现权重按“单个稀有附魔书候选”对待。沿用 Java 1.12.2 的旧村民交易体系，不引入 1.14 的工作站、职业方块、村民等级条或补货工作日程。

## 验收标准

- 伐木不会把木屋/原木墙误判成整树连锁；相邻树冠不连锁。
- 连锁每破坏 1 块都独立进行耐久/Unbreaking 判定，工具损坏立即停。
- 屠宰只增强指定动物，打玩家/村民/怪物无额外伤害；互斥生效。
- 捷足四级移速准确，无药水图标；与耕地行者/速度药水叠加顺序正确。
- 夜视只影响佩戴者视觉，服务端光照与怪物生成不变。
- 八种附魔都能从附魔台和旧版图书管理员体系随机出现，并能按规则铁砧合并。
