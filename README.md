# 聆竹の休闲田园经济 (LisBam's Pastoral Economy)

面向 **Minecraft Java Edition 1.12.2 / Forge** 的休闲田园经济模组。

它把 1.12.2 的生存主循环调整为 **休闲种田 + 蟹笼捕捞 + 每日行情 + 商人交易 + 绿宝石现货 + 村庄交通 + 长期经营**。
原版的挖矿、探索、下界与末地、Boss 战和传统战斗**全部保留**，模组只是提供了另一条不依赖挖矿和刷怪的资源获取路径。

| 游戏版本 | Minecraft Java Edition **1.12.2** |

## 下载与安装

1. 安装 **Minecraft 1.12.2** 并装好 **Forge 14.23.5.2859**（或同系列 14.23.5.x）。
2. 从本仓库的 **[Releases](../../releases)** 页面下载最新一版的 `LisBam_PastoralEconomy-1.7.jar`。
3. 把 JAR 放进游戏目录的 `mods/` 文件夹（`.minecraft/mods/`），启动游戏即可。
4. **客户端与服务器必须使用同一份完整 JAR**。更换 JAR 前请完全退出游戏及对应 Java 进程，删除旧副本后再放入新包。

> 注意：本模组同时是 Coremod（会为附魔台等追加少量原版改写），请勿与其他改写同一原版类的模组混用。

## 核心循环

1. 种植并收获农作物、畜牧产物，或用**蟹笼**进行被动捕捞。
2. 查看当天行情，找到村庄里的**商人**。
3. 出售商人当天收购的商品，赚取**金币**。
4. 从商人当天出售的 8 项商品中购买所需资源。
5. 用资源扩建农场、建筑、仓储和红石自动化。
6. 发现村庄并付费接入**交通网络**，解锁更多商人与每日商品选择。
7. 长期重复经营，**没有强制通关时限**。

## 主要内容

### 🪙 金币与经济

- 金币是纯账户余额，显示在屏幕**右上角**（`金币 12,580` 格式），不占物品栏、不掉落、不能被别人捡走。
- 初始金币 0，不设上限；**1 小麦基础卖价 = 50 金币**。
- 死亡会扣除随机 **10%～30%** 余额（不低于随机 1,000～2,000 金币），并在聊天框以红字提示。

### 📈 每日市场行情

- 行情按 **Minecraft 世界日**（24,000 ticks）刷新，每天涨跌，**同一天重登、重启、切维度都不会重抽价格**。
- 不同类型商品有各自的波动区间，例如核心农作物单日变幅 8.75%～35%，珍宝收藏品仅 2%～8%。
- **市场行情书**（书 ×1 + 小麦 ×1，无序合成）可随时打开行情界面，查看全部 29 种收购商品与购买目录，以及最近 **30 个世界日**的价格曲线；支持中文名 / 全拼 / 首字母 / 商品 key 搜索。
- 在库存界面把鼠标悬停在可出售物品上，Tooltip 会直接显示**今日价**。
- 可用 `moreStableMarketVolatility` 设置切换为更稳定的旧式波动模式。

### 💎 绿宝石现货（炒币）

- 商人的“炒币”页可用金币买卖**真实原版绿宝石**：买入进背包、卖出从背包扣货。
- 全服共用一条独立日价：初始 1,000 金币/个，限制在 **300～3,000** 之间，每天只更新一次。
- 买卖手续费各 **4%**，界面预览金额，实际结算全部由服务端复核。

### 🧑‍🌾 商人

- 商人是独立 NPC（不是原版村民职业），随机中文姓名与四种农作服装，**全天 24 小时**营业。
- 每个有效村庄至少维持 3 名商人（随村民数增长，不设上限），被杀后自动补足。
- 每名商人每天：**收购 6 项**（核心农产 4 + 次级农产/畜牧 2）、**出售 8 项**（品质按 普通 40% / 罕见 30% / 稀有 20% / 珍宝 10% 独立抽取）。
- 商品按品质分池轮换，珍宝每天每名商人限 1 个；有限库存跨天才刷新。
- 新增物品 **交易凭证**（八金粒 + 一纸）可授权原版箱子参与交易；**出货箱**（八木板 + 一凭证）每天清晨按当天收益的 **70%** 自动结算并分给箱内凭证所属玩家。

### 🦀 蟹笼

- 靠水自动捕捞的容器方块（铁锭 ×4 + 铁栅栏 ×4 + 陷阱箱 ×1），任一相邻方块接触水即可工作，**不需要大片开放水面**。
- 20 格容器：0 号槽放钓竿、1 号槽放生肉饵料、2～19 号槽存放产出。
- 每轮等待 100～600 秒；饵钓每级减 100 秒，海之眷顾提升宝藏权重；生肉饵料让收获速度约翻倍。
- 漏斗可自动化输入输出；钓竿在蟹笼中**不消耗耐久**。

### ✨ 十三种新增附魔

**丰收、耕地行者、田园眷顾、精耕、伐木、屠宰、捷足、夜视、攻速、范围、掉落吸附、百炼如新、束锋诅咒。**

- 除诅咒外都能通过附魔台、图书管理员交易、商人珍宝附魔书或铁砧获得。
- 例如：**丰收**在锄头/斧头/剪刀上额外增产作物与羊毛；**伐木**一次连锁整棵树；**耕地行者**不再踩坏耕地并可在耕地上加速；**捷足**大幅提升护腿移速；**掉落吸附**让剑与击杀自动收拢掉落物。

### 🚉 交通网络与出行装备

- **交通方块**（红石块 ×4 + 铁块 ×4 + 指南针 ×1）按距离付费接入：第一次自建节点免费，之后按到最近已接入节点的水平距离收费。
- 在已接入的交通站可一键**付费接入最近的未解锁村庄**，费用与余额由服务端重新核验。
- 原版背包新增**肩部装备槽**：可装备鞘翅与三种**背包**（普通 27 格 / 高级 54 格 / 超级 108 格），也可装备**翅膀**获得创造式飞行。
- 新增方块 **区块加载器**：红石充能时只让自身 1 个区块保持加载，掉电或破坏即取消。

### 🌾 休闲化生存规则

- 世界首次启用模组时默认开启 **keepInventory**（死亡保留物品），之后可自行关闭。
- 主世界**不再自然生成敌对生物**；刷怪笼、刷怪蛋、命令与结构生成不受影响，下界与末地保持原版。
- 敌对生物（含苦力怕爆炸破坏方块）的 AI 与行为**完全保留 1.12.2 原版**。
- 动物会额外掉落骨头；成年牛与哞菇**每个世界日只能挤奶 1 次**（可在配置中关闭）。

## 配置

在 Mods 列表的本模组设置中，或服务器 `config` 文件中可调整，主要包括：

- `moreStableMarketVolatility` —— 使用更稳定的市场波动模式（默认关闭）。
- `gameplay.disableMilkingCooldown` —— 取消每日挤奶限制，恢复原版连续挤奶（默认 `false`）。

**市场价格由逻辑服务端决定**，多人服务器应由服主修改服务器配置；客户端本地设置无法改变远端服务器价格。

## 从源码构建

需要 **JDK 8**（源码与目标字节码均为 Java 8）。

```bash
./gradlew build
```

构建完成后，可安装的重混淆成品会由 `exportReleaseJar` 导出到：

```text
release/LisBam_PastoralEconomy-<version>.jar
```
